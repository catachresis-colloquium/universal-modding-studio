= Enaction preview adapter seam

This directory contains the host-neutral contracts of the optional Enaction
preview adapter:

* `preview-request.schema.json`: the request that
  `SimulationAdapter::preview` writes to the runner's stdin;
* `preview-response.schema.json`: the response
  (`ums-enaction-preview-response/2`) that `ProcessPreviewAdapter` returns
  after a replay-identical, validator-accepted preview. Version 2 carries one
  file per document (`runnerOutput`, optional `mindTrace`).

The adapter is `crates/ums-profile-sdk/src/preview.rs` (ADR-0019, Proposed).
Its protocol is tested against stub binaries that copy the real command
lines; the explain lens is tested on documents the real runner wrote
(`vendor/idaptik/weevil-corridor`). A preview against the real binaries is an
ignored test, not run in CI (it passed by hand on 2026-11-14); see
`docs/ENACTION-ADAPTER.adoc` and
`docs/DESIGNER-QUICKSTART.adoc`.

The profile owns translation from its UMS model into runtime definitions.
The adapter owns deterministic request/trace transport only. It must never
acquire IDApTIK or Slavia ontology.
