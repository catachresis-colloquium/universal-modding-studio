== What UMS gains

A `ProcessPreviewAdapter`, the first non-test `SimulationAdapter`. It runs a
game's pre-built headless runner and then the Enaction validator (later the
Enaction reducer) as separate processes over canonical data. The designer
then gets a replay-checked, evidence-labelled belief report through
`ums-profile preview --explain`.

UMS gains no Cargo dependency on Enaction or on any game (ADR-0010, ADR-0016).
The preview fails, never falls back to a stub, when a binary or root is
missing.

  CI-gated. `just roundtrip-idaptik` cannot pass against IDApTIK `f71718b`,
  because IDApTIK has no `examples/package-runner.rs`. A six-line runner

  forbids TypeScript. No exemption is recorded. Exempt it or port it: the
  choice is the owner's (plan question Q5).

  it reads `/home/user/IDApTIK`. With that path present, all 131 tests pass
  at `09dd204`.

  `../chronicles-of-slavia`. It passes with `SLAVIA_ROOT` pointing at a
  checkout elsewhere.
