= UMS Studio: first local authoring slice
:toc:

This is an *alpha workbench*, not a released game editor or a deployed website.
It provides a Vue 3 browser interface, Vite frontend tooling and a Bun
loopback-only HTTP bridge to the existing Rust profile tools. Marid is
deliberately NOT a runtime dependency: it is an experimental Julia-first
framework, and this editor does not need a Julia backend.

== Prerequisites

* Bun (install via the official Bun distribution).
* Rust toolchain matching the repository rust-toolchain.toml, with cargo.
* For IDApTIK compilation only, a sibling game checkout containing the actual
  versioned contracts. Set `IDAPTIK_ROOT` to its absolute directory.
* Run from the UMS repository, not a copy of apps/studio in isolation.

== Local start

In terminal 1:

[source,sh]
----
cd apps/studio
bun install
IDAPTIK_ROOT=/absolute/path/to/IDApTIK bun run api
----

In terminal 2:

[source,sh]
----
cd apps/studio
bun run dev
----

Open http://127.0.0.1:5173 . Both the API and Vite are bound to loopback.
For development only. Do not expose either server to the public Internet.

== What actually works

* Loads both versioned profile descriptors directly from the current repository.
* Loads IDApTIK's authored Ghost Lobby UMS source and the bounded Slavia fixture.
* Provides an accessible entity inventory, persistent selection when changing
  lenses, descriptor-driven palette and explicit evidence/guarantee levels.
* Edits a session-local JSON draft; Reset and Export Draft do not modify the
  checked-in source or game contract.
* For IDApTIK, compiles through the real `ums-profile` Rust CLI and the
  game-owned contract in `IDAPTIK_ROOT`. On success downloads the resulting
  package; errors/refusals are displayed instead of issuing a fake artefact.
* For Slavia, executes the real declared-profile validator. No compiler,
  game-loader, live simulation or graphical scene is claimed.

== Trust boundaries

The Bun API has two fixed profiles and two fixed checked-in source fixtures.
It runs a fixed, argument-array Rust CLI without a shell. A browser draft
cannot change IDApTIK's contract identity or contract file paths, which are
pinned to the checked-in original. The bridge runs on 127.0.0.1 only and
requires a same-local-origin studio header for POST.

This is not safe for hosting publicly: there is no account authentication,
sandbox, per-user isolation, resource scheduler or production process policy.
Compiled packages still require game-owned loader checks. The generated package
does not constitute a proof that arbitrary content is safe.

== Verification

[source,sh]
----
cd apps/studio
bun test server
bun run typecheck
bun run build
----

The tests check profile allowlisting, fixed game contract refusal, immutable
canonical sources and the Slavia design fixture boundary. CI runs those
checks and builds the Vue frontend. With `IDAPTIK_ROOT` present, a human can
exercise a real compile, but full runtime round-trip remains guarded by the
existing Rust CI workflow, not by the browser UI.
